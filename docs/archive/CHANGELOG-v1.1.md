# Loadnote v1.1 — Product Focus Cleanup

## Changes
- Removed/de-emphasized developer-facing API navigation from the consumer UI.
- Removed/de-emphasized the current Form Analysis navigation.
- Reframed generic workout generation toward program building.
- Reduced the prominence of nutrition in navigation.
- Added a concise product-focus message emphasizing Train → Log → Adapt.
- Version bumped to 1.1.0.

## Product principle
Loadnote's primary loop is:
Workout → Log → Analyze → Adapt → Next Workout → Coach.

Experimental/developer features should remain available only through development paths until they are production-ready.
