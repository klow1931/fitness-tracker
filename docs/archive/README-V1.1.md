# Loadnote v1.1

This release is a product-focus cleanup of v1.0.

### Core experience
- Train
- Log
- Progress
- Coach
- Profile

### De-emphasized
- Developer/API controls
- Current form-analysis experience
- Generic workout generation
- Nutrition as a primary destination
- Excess tooling in the main flow

The goal is to make Loadnote feel like an adaptive strength-training product rather than a collection of fitness utilities.
