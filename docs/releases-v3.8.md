# Loadnote v3.8.0

Workflow polish, build 30800. No data-schema or prescription changes.

- Coach Today puts its primary next action first. The duplicate chat card is removed; Ask Coach remains in the main tabs and the companion remains in More tools below the active section.
- Profile groups goal/schedule, optional athlete history and powerlifting lift mapping into an ordered setup checklist. Saved versus unrecorded context is explicit. Non-powerlifting goals keep competition mapping under Advanced setup instead of the main checklist.
- Setup actions share mobile sizing. Repeated explanations move into optional guidance; account status remains honest about configured sync.
- Existing reviewed setup/intake/mapping forms remain authoritative. Editing goal/schedule preserves recorded intake and existing workouts. No new automatic prescriptions or medical interpretation.
- Browser coverage exercises narrow widths, larger text, checklist status, goal changes, intake persistence, saved-training preservation and Coach action hierarchy.

Physical iPhone/Safari keyboard, navigation clearance and reload acceptance still require the separate mobile acceptance checklist. Automated Chromium and unsigned native builds are not a physical-device test.
