# Loadnote v3.21.0 — Installable Android beta and emulator acceptance

The new Android beta workflow compiles a debug-signed, installable development APK under `app.loadnote.mobile.beta`, labelled Loadnote Beta. Its sandbox is separate from the future production identity. The build verifies version/build, debug channel, signature, compiled bytecode, packaged local assets and the restricted permission allowlist. The APK, SHA-256 checksum and reports are uploaded for 14 days only after emulator acceptance succeeds. Production release signing is not provisioned; the existing unsigned Android and iOS compilation gates remain intact.

Instrumented tests run the real packaged WebView and native Filesystem bridge on a disposable API 35 emulator with Wi-Fi/data disabled and airplane mode enabled. They cover explicit setup/intake saves, a reviewed workout, a fingerprinted JSON cache round-trip, cancellation and confirmation of import, preserved draft values, background/foreground, activity recreation, force-stop cold launch and reinstall/update with the same APK/certificate. Test DOM actions are not physical touch/soft-keyboard acceptance. Cache verification and synthetic file input are not an external file-picker or share destination test. The runner refuses physical-device serials and requires an explicit disposable-beta flag before clearing its synthetic sandbox.

CI signing certificates are ephemeral. Cross-run APK upgrade continuity is not established; retain external verified backups, and do not uninstall an app containing valuable data to bypass a signature mismatch. Use a stable locally owned debug certificate for ongoing personal testing. This release does not configure production signing, publish to Google Play or claim store readiness.

See [Windows testing guide](android-beta-windows.md), [remaining physical-device gate](native-device-acceptance.md) and [free-first monetization options](monetization-options.md). No ads, billing, tracking, analytics service or health-data targeting is added. Version 3.21.0/build 32100, schema 32 unchanged; existing records and prescriptions remain unchanged.
