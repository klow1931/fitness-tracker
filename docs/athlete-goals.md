# Athlete goals and weekly planning — v2.9

Home → Today's plan & weekly rhythm contains Goals & weekly review alongside the existing schedule. Create a goal, optionally add an event/date, weight-class label, training experience, available weekdays (0 Monday through 6 Sunday), session duration and equipment. Powerlifting targets are aspirational values stored in kg and displayed in the selected unit. They are not training maxes, current capacity or program prescriptions. Other sport names are supported as context only; decision logic is still powerlifting-specific.

Link existing training blocks or individual scheduled sessions in the goal editor. A linked block includes workouts by its date range and scheduled sessions with that block ID (otherwise by date association). Explicit schedule block IDs take precedence over date-derived associations. Individual session links use schedule IDs. These links do not rewrite workout or schedule records. If linked data is later removed, retain the IDs and show unavailable-link guidance; edits can remove obsolete links.

Schema 17 adds `athleteGoals: [{id,revisions:[{recordedAt,context}]}]`. Legacy `goals` remain intact. Older backups acquire an empty collection. Import and load strictly validate goal history, bounded fields, units, dates and revision chronology; normal backups and recovery snapshots preserve it. Status changes to completed/archived append revisions rather than deleting history. Athlete goals have independent explicit links, allowing multiple goals without automatically reallocating sessions.

`LoadnoteGoals.list(records,knownAt)` and `week(state,{asOf,goalId,knownAt,retrospective})` expose dated views. The home review defaults to current corrected goal/block context, clearly labeled, and excludes future workout dates. Strict API replay uses goal/block knowledge cutoffs and existing workout revision replay. Legacy missing workout timestamps still carry existing replay limitations. Schedule history retains its existing as-of behavior. Goal links and targets are not consumed by live decision rules in this release.

Weekly ranges use Monday–Sunday. Completed evidence ends on the review date; later scheduled sessions can still be shown. Counts distinguish completed, skipped, cancelled, upcoming and unconfirmed sessions. Adherence is completed / (completed + explicitly skipped), not a claim about all intended training. Performance trends reuse block analysis and require three eligible days; RPE and planned-work coverage keep existing sparse-data guards. This is descriptive evidence, not a prediction that a goal will be achieved. No automatic program edits, recovery scores, prescriptions or non-powerlifting coaching were added.

Testing includes revision history, archive status, chronological access, link association, no future-workout leakage, nonmutation, legacy migration, backup roundtrip, kg/lb conversion, sparse data, offline browser persistence and failed writes. Desktop/mobile Chromium checks do not replace a physical iPhone Safari/PWA check.
