# Loadnote v2.93.0 — Shared Training Knowledge

Decisions, offline Coach and Companion use one descriptive muscle-workload model. The collapsed Decisions panel shows the latest seven calendar days of current corrected workout history, direct sets, indirect exposures, actual-RPE coverage, RPE 7–10 counts, unmapped records and incomplete/hold records. Main and secondary lifts contribute alongside accessories. Indirect exposure is never assigned an arbitrary fractional set value. Technical weightlifting sets and other-mode work stay separate. Unknown history completeness remains explicit; counts cannot establish sufficient stimulus, growth or recovery.

Athletes confirm primary/secondary muscles and training mode per stable exercise identity. Suggestions fill a form only. Optional `exerciseCatalog[].muscles` metadata survives normalization, backup/import and identity merges; conflicting merge mappings are cleared for reconfirmation. Existing schema 25 backups remain valid with unknown mappings. Edits create recovery snapshots and commit only after persistence succeeds. Current mappings interpret current corrected history; historical as-recorded mapping replay is not implemented.

Shared source-backed explanations cover hypertrophy volume, loading, effort, exercise selection, rest and gradual progression; general athlete planning context; and technical Olympic lifts/derivatives. Sources: IUSCA 2021 hypertrophy position stand (doi:10.47206/ijsc.v1i1.81) and NSCA 2023 weightlifting for sports performance (PMID 36952649). Reference values are population guidance, not dose thresholds. Existing pain/injury capability limits take precedence. No training edits, new readiness algorithms, automatic workload adjustments, sport-specific program generation, weightlifting cycles or form analysis are claimed.

Unsigned development build 29300. Local unit, syntax, mobile/native source consistency and desktop/mobile browser validation are required. iOS/Android compilation runs in GitHub Actions; signing, distribution and physical-device acceptance remain separate.
