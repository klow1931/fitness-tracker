# Loadnote v3.27.0 — Calendar day shortcuts

Tap a calendar day to log a completed workout, schedule a new workout, or enter nutrition for that date. Today and past days support all three; future days offer scheduling. View this day keeps existing workout/plan details available.

- Workout entry carries the selected date into the full logger. Existing unsaved work requires confirmation before changing dates; linked or edited sessions cannot be silently moved.
- Scheduling carries the chosen date into the existing reviewed-plan flow. New users without a plan can capture one in the logger for that date; no empty workout or automatic completion is created.
- Nutrition opens Add food with the chosen day and its existing entries loaded.
- Calendar date keys follow local time, including timezones ahead of UTC. Keyboard, Escape and focus return are supported.

No schema migration; normal review/save controls still commit entries.
