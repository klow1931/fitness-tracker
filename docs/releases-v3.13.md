# Loadnote v3.13.0

Daily workout interface refinement, native build 31300. Schema 32 unchanged.

Today and the Train launcher keep Start/Resume above an expandable exercise preview. The saved session goal supplies a short Focus line; program week/phase and estimated duration remain visible when recorded. Estimates are never manufactured for a manual session. Existing review gates and other-date draft priority remain authoritative.

The current-set controls can copy the matching prior set's load and reps/hold duration. Existing values require confirmation; cancelling keeps the draft unchanged. Actual RPE and completion are never copied, cleared or marked complete by this shortcut. Other sets are unaffected. Rest can start at 90 seconds or three minutes from the cockpit, then use existing pause/extend/stop controls. Current exercise swaps use the existing dialog and deviation workflow. Load adjustments include units in their accessible names.

Finish shows a concise saved/partial result, recorded deviation, review availability and next workout. Full plan comparison and training evidence remain in native disclosures. Blocking/unresolved notices and accepted before/after changes stay visible. The duplicate dismiss button is removed when the handoff already provides Done; edit recaps retain dismissal. No automatic training change, record rewrite or storage migration.

Browser coverage includes keyboard disclosures, 320px light/dark screenshots, rep/hold copying with accept/cancel, RPE/completion preservation, draft reload, rest actions, swap reachability and save/next-session routing. Physical iPhone Safari/VoiceOver acceptance remains to be checked; CI and screenshot evidence are recorded in the PR.
