# Loadnote v2.77.0 — Fast Start Training

- Added a training-first launch surface when the athlete taps Train.
- Prioritizes Resume whenever an unfinished local workout exists, including when a different session is scheduled today.
- Scheduled workouts preview the planned exercises before Start and then use the existing logger directly.
- Home Start/Resume actions hand off directly into the compact logger without an extra configuration screen.
- Date, notes, timing, session intent and planned-work setup remain available behind Workout options before execution begins.
- Existing v2.75 execution-first workout behavior, workout persistence, history, kg/lb conversion, RPE/e1RM logic, programming, fatigue/status and schema v25 remain unchanged.
