# Loadnote v3.0.0 — Shared coaching intelligence and practical plan control

The daily coaching brief connects the reviewed program, current training, athlete reports, missing evidence, sport conflicts and eligible future changes. Decisions, Coach and Companion use the same fresh records; follow-up questions read the current state rather than trusting earlier assistant claims. Action buttons lead directly to the appropriate review.

- Wave loading in the strength Program designer: three-week loading waves, explicit percentages/reps, an athlete-chosen base step, partial-wave boundaries and a fixed deload. Existing linear plans remain unchanged. The legacy wave menu opens this reviewed designer. Meet event planning retains its separate reviewed phase policy.
- Manage programs: preview and cancel only unperformed sessions from today onward, with a reason and confirmation. Keep completed work, earlier unresolved dates and frozen plans. Restore through a checked, explicit workflow while dates remain current and Calendar/replacement plans do not conflict.
- Optional shorter future sessions: preview omission of athlete-selected phase/meet accessories for one date; preserve primary, light and variation work exactly. Reduced accessory work is not an equivalent dose and does not authorize shorter rest.
- Fixed cockpit target-fill/load-step shortcuts calling an undefined refresh function; keyboard focus now completes without an exception.
- Compact evidence, progressive disclosure, touch-friendly coaching actions and reduced-motion support.

Schema 31 adds the append-only program cancellation journal, including backup manifests, import previews and conflict-first sync. Build 30000. No diagnosis, automatic chat prescriptions, technique analysis, measured recovery score, policy learning or verified human-coach review is claimed.

Validation and synthetic desktop/mobile demos are recorded in the v3.0 walkthrough. Unsigned native compilation is not device acceptance.
