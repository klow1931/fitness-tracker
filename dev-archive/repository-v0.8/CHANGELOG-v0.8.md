# Loadnote v0.8 — Adaptive Mesocycle Engine

- Added schema v8 with persistent per-program mesocycle state.
- Added week-to-week adaptive programming engine.

- Main lifts receive training-max-based weekly prescriptions when training maxes are available.

- Program workouts now store week, block, and decision metadata.
- Added “Why this decision?” explanation in the Active Program card.
